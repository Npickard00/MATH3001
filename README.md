# MATH3001
Repository of code and associated datasets for analysis done as part of the MATH3001 dissertation.

Interactive map displaying the proposed and completed flood mitigations as part of the Leeds Flood Alleviation Scheme, Phase 2 can be accessed [Here](https://leeds365-my.sharepoint.com/:u:/g/personal/mm21n2p_leeds_ac_uk/EcLEDUMXPNxKoGePSXkHKqYBmmauIv7Ajs4_tQgiDPRyrg?e=fkI75W)
Note: You need to first download the file and then open it to view the map, it may appear blank when you preview the download


With the code used to produce this in the CODE file. Changes can be made to the location the map is focused on, as well as the location of flood mitigation icons and the images which load, enabling it to be adapted to other flood alleviation schemes.
